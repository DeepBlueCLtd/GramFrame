# Sample audio attribution

The recordings in this directory are short excerpts of industrial and machinery
noise used as sample input for GramFrame. All four come from the
[Work With Sounds](https://commons.wikimedia.org/wiki/Commons:Work_With_Sounds)
collection on Wikimedia Commons and are licensed under
[Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
The licence was verified on each file's Commons description page (the
`{{CC-BY 4.0}}` permission template, backed by VRT permission ticket
2014082510012677) on the retrieval date given below.

Every file here has been changed from the original in the same way: a
30–45 s segment was cut from the recording, the audio was resampled to 16 kHz,
mixed down to a single channel, and re-encoded as 16-bit PCM WAV. No other
processing (filtering, normalisation, noise reduction) was applied.

## hot-bulb-diesel-engine.wav

- **Title:** WWS Hotbulbengineworking.ogg — "Hot bulb engine, working" (Pythagoras-Drott
  mechanical works, Norrtälje; large diesel-driven hot bulb engine built 1932,
  close-mic recording with the generator not running)
- **Author:** Work With Sounds / Torsten Nilsson
- **Source:** https://commons.wikimedia.org/wiki/File:WWS_Hotbulbengineworking.ogg
  (original at http://www.workwithsounds.eu/sound/hot-bulb-engine-working/)
- **Licence:** CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/
- **Changes:** trimmed to 50–90 s of the original (40 s), resampled from
  44.1 kHz to 16 kHz, mixed from stereo to mono, converted from Ogg Vorbis to
  16-bit PCM WAV
- **Retrieved:** 2026-09-05
